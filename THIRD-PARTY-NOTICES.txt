Third-party notices for dlqq-llm-train
========================================

This file covers only components distributed with dlqq-llm-train. Training
dependencies (torch / numpy / transformers and their transitive dependencies)
are installed by the user into the project Python from the Environment tab;
they are not shipped with this repository or its release package, and their
licenses are not bundled here.

Version and license lines below must match the actual bundled files. Python
versions come from .runtime/python/VERSION.txt and `python --version`; frontend
versions come from the bundle headers or official package metadata; license
texts and copyright lines come from the bundled LICENSE files.
