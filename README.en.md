# 鸫楼桥鹊AI大语言模型训练

#### Description
基于 transformers GPT-2 的字符级语言模型训练与对话工具。自带本地 WebUI，支持语料切词缓存、从零训练、断点续训、流式对话和 OpenAI 兼容桥接；不加载任何预训练权重，权重保存为 HF 标准目录。Windows 双击启动，适合小模型学习、实验与二次开发。
